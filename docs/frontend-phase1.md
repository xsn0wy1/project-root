# Frontend simplification — Phase 1

The user approved Phase 0 and requested Phase 1 only. Database/domain code and API contracts remain frozen. This phase has separate work-package commits and pauses before the Phase 2 pilot.

## WP-1.1 — translation wrappers

The globally loaded `theme.css` now gives `i18n-text` its existing `display: contents` value. All 174 static attributes and the one generated by `HospitalI18n.mark()` are removed. The rule will move into `base.css` with WP-1.2. Text, element hooks and other inline styles are unchanged.

The duplicate inventory now includes the serialized shorthand declaration as well as expanded properties. Chromium returns empty longhand values for unresolved `var()` shorthands; the old inventory could therefore mistake `border: 1px solid var(--ambulance-line)` and `border: 1px solid var(--patient-line)` for duplicates. A focused parser check rejects that case. Remeasuring both source copies gives **89 page-sheet selector/declaration groups (113 extra occurrences)**, rather than 109/133. The whole selector-list subset has 68 groups. No differing variables or near-equal colors are merged.

## WP-1.3 — cache-busters

`asset_url($path)` in `shell.php` now appends the single `ASSET_VERSION` value and escapes the completed URL for HTML. All stylesheet/script output uses it, including auth, registration, public surveys and local vendor resources; page configurations contain plain paths. The 27 handwritten view version strings are gone. Existing query parameters retain their separator and HTML escaping. These query-string changes are intentional; stylesheet/JS/image bytes and vendor integrity attributes are unchanged. The one pre-existing image query in plain CSS is retained. The fresh 636-pair replay compares the complete final CSS and URLs against accepted WP-1.1 source (2938b9c), independently confirming the shared-sheet package. One map API-settle timeout was resumed with unchanged source. The translation/DOM coverage tool also verifies the shared version on every local stylesheet/script in all 25 fresh renders.
